# Changelog

All notable changes to this project are documented here.

## 1.0.0 — 2026-08-05

- Added an asynchronous HTTP/2 availability client.
- Added a batch CLI with EN/RU output and grouped result files.
- Added a resumable exhaustive three-character scanner.
- Added an EN/RU Telegram bot with persistent language settings.
- Added Docker, CI, tests and bilingual documentation.
- Distinguished `TAG_TAKEN`, `RESERVED_TAG`, `INVALID_TAG` and network failures.
